# Yakobson V. — варианты новой главной (демо)

Демонстрационная копия для показа. **Открыть:** https://paul1l.github.io/yakobsonv-navigator-demo/

Сверху каждой страницы — полоса «Демо» для переключения вариантов:

- **Тёмный (навигатор)** — новая главная «Навигатор по задачам клиента» в палитре живого сайта [yakobsonv.com](https://yakobsonv.com/):
  4 задачи с подборками, поиск по сайту, 3 избранных кейса, этапы работы, автор, связь.
  https://paul1l.github.io/yakobsonv-navigator-demo/ru/
- **Светлый (прототип)** — светлый макет с анимированной сценой на первом экране.
  https://paul1l.github.io/yakobsonv-navigator-demo/light/

Это статические сборки тестовых копий, а не рабочий сайт: страницы закрыты от индексации (`noindex`, `robots.txt`),
Яндекс.Метрика выключена, формы заявок никуда не отправляют данные.
