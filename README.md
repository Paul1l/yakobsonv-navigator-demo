# Yakobson V. — новая главная (демо)

Демонстрационная копия для показа. **Открыть:** https://paul1l.github.io/yakobsonv-navigator-demo/

- **Основной вариант** (главная демо): светлый дизайн, тема переключается на тёмную в палитре живого
  [yakobsonv.com](https://yakobsonv.com/) — кнопка в шапке (луна / солнце) или строка в мобильном меню.
  Первый экран — интерактивная орбита направлений: «Сайт / Трафик / Автоматизация» вокруг кольца, карточка
  выбранного направления под ним и «Подробнее» с составом работ и кейсом; на компьютере — короткий автообзор.
  При прокрутке кольцо уходит в фон и сопровождает по странице.
- **Джарвис-гид** — тот же сайт, но пояснительные тексты разделов «произносит» анимированное кольцо: при прокрутке
  оно перелетает от раздела к разделу и текст проявляется из него по словам.
  https://paul1l.github.io/yakobsonv-navigator-demo/jarvis/
- **Навигатор по задачам** — альтернативная главная: https://paul1l.github.io/yakobsonv-navigator-demo/ru/

Переключение — полоса «Демо» вверху страницы. Это статические сборки тестовых копий, а не рабочий сайт:
страницы закрыты от индексации (`noindex`, `robots.txt`), Яндекс.Метрика выключена, формы никуда не отправляют данные.
