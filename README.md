# Yakobson V. — новый сайт в стиле «Джарвис-гид» (демо)

Демонстрационная копия для показа. **Открыть:** https://paul1l.github.io/yakobsonv-navigator-demo/

- **Полный сайт** (основной вариант, корень ведёт на `/ru/`): весь сайт в стиле «Джарвис-гида» — главная со сценами гида
  (прокрутка ведёт гида по разделам, текст разворачивается из его центра, у каждого направления — окно с подробностями)
  и все внутренние страницы (услуги, кейсы, цены, о компании, подход, контакты, статьи, SEO-посадочные, кабинет) на RU и EN.
  Тексты, логотип и название — с живого [yakobsonv.com](https://yakobsonv.com/). Тема: светлая (гид) или тёмная в палитре
  живого сайта — кнопка в шапке. https://paul1l.github.io/yakobsonv-navigator-demo/ru/
- **Джарвис-гид (одна страница)** — исходный одностраничный прототип гида: https://paul1l.github.io/yakobsonv-navigator-demo/jarvis/
- Прежние адреса: `/light/` ведёт на полный сайт; прежние варианты (светлая главная с орбитой, «Навигатор по задачам») —
  в истории этого репозитория.

Переключение — полоса «Демо» вверху страницы. Это статические сборки тестовых копий, а не рабочий сайт:
страницы закрыты от индексации (`noindex`, `robots.txt`), Яндекс.Метрика выключена, формы никуда не отправляют данные.
