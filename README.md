# Yakobson V. — новая главная «Навигатор по задачам клиента» (демо)

Демонстрационная копия для показа концепции. Тёмный вариант в палитре живого сайта [yakobsonv.com](https://yakobsonv.com/).

**Открыть:** https://paul1l.github.io/yakobsonv-navigator-demo/

- Это статическая сборка тестовой копии, а не рабочий сайт. Страницы закрыты от индексации (`noindex`, `robots.txt`).
- Форма заявки здесь не отправляет данные (рабочего API нет). Яндекс.Метрика выключена.
- Главная — новая (навигатор: 4 задачи, подборки, поиск по сайту); остальные страницы — как на живом сайте.
