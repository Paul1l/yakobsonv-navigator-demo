When we don't fit

We'll say no upfront, if

If your case matches any of these, we'll pass. Not on principle — because the outcome is predictably bad. Better to save both sides a few months.

  • You need top rankings in a month

    Technical fixes show up in Search Console within 2–4 weeks, commercial rankings 3–6 months, steady pipeline 6–12. If the budget is built around a 4-week timeline, SEO is the wrong channel — go to paid.

  • Your site is a one-off landing page

    Large-scale page creation and live dashboards pay off on 100+ page catalogues with long-tail demand. On a single-page or 5-page landing, our methodology is overkill — a targeted audit + a separate copywriter is cheaper.

  • You only pay for “guaranteed top rankings”

    No honest SEO engineer gives ranking guarantees — algorithms shift, results are personalised, competitors move too. We guarantee the process, KPIs and transparency. Not a SERP slot.

  • There's no internal project owner on your side

    We need one person on the client side who can sign off on the sample page, answer product questions and approve the brief. If all decision-makers are “not until next quarter,” work stalls in review. Better to wait for the window.

  • Content is confidential without an NDA

    We sign NDAs from day one — but won't work on “verbal trust” with sensitive niches (legal, fin services, medical) without a written confidentiality framework.

Stack we work on

CMS · direct admin and API work

  • Bitrix (REST + direct SQL patches)
  • WordPress + WooCommerce (Application Passwords)
  • Tilda (PRO+ API)
  • OpenCart, MODX, Joomla, Drupal
  • Custom PHP/Laravel/Symfony engines

Production process · 5 stages

  • Brief assembly: SERP, competitors, specs from the CMS
  • HTML drafting against the reference structure
  • Validation checklist: Schema, FAQ, spec tables
  • Auto-publish through the REST API with changelog
  • Independent QC across 10 criteria × 10 points

SEO and analytics tooling

  • Search Console API + Yandex.Webmaster API
  • Topvisor / Serpstat / Ahrefs (client-side)
  • Log analysis via GoAccess + custom scrapers
  • Schema Markup Validator, Rich Results Test
  • Lighthouse / PageSpeed Insights for Core Web Vitals

Infrastructure and automation

  • Python (audit / QC / validation scripts)
  • Node.js (generators, CLI tools)
  • REST API (Bitrix, WordPress, Tilda)
  • Next.js / React (live dashboards on Vercel)
  • Astro / Tailwind (static and landing pages)

Not listed publicly ≠ we don't work with it. Exotic CMS or specific stack — one short call and we'll tell you honestly whether we can handle it.
